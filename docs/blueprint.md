# **App Name**: ProExam Forge

## Core Features:

- User Authentication & Roles: Secure registration and login for Admin, Coaching Centers, and Students, with role-based access control to platform features and content.
- Coaching Center & Exam Management: Coaching centers can manage their profiles, create and schedule various types of exams (MCQ, True/False, Multiple Correct) with specified time limits, negative marking, and language settings.
- Dynamic Exam Link Generation: Upon exam creation, a unique, shareable URL is generated for students to access. The system enforces exam start/end time restrictions.
- Student Exam Interface & Submission: Students attempt exams with an in-interface timer, question navigation, mark-for-review options, and automatic submission on time expiration. Includes roll number validation.
- Instant Results & Ranking: After submission, students immediately view their score, correct/incorrect answers, and time taken. Coaching centers view detailed student results, automatic score-based ranking, and general analytics.
- AI Practice Exam Generator: A generative AI tool for students to create personalized practice exams on any topic, specifying the number of questions, language, and difficulty.
- Subscription Plan & User Administration: Admin dashboard for managing coaching center subscriptions (Free/Pro plans), approving/blocking users, and platform-wide analytics and oversight.

## Style Guidelines:

- Primary color: A sophisticated, trustworthy blue (#2669DA) to convey professionalism and focus, setting the platform's reliable tone.
- Background color: An ultra-light, subtle blue-grey (#F7F8FB) to ensure high readability and a clean, unobtrusive canvas for content.
- Accent color: A vibrant, clear purple (#8B4ADF) to highlight key actions, alerts, and interactive elements, providing energetic contrast to the primary blue.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, tech-savvy appearance, suitable for headings and calls to action. Body text font: 'Inter' (sans-serif) for exceptional legibility and neutral professionalism, ideal for detailed exam content and platform information.
- Use a consistent set of line-art icons that are simple, universally recognizable, and contribute to a clear, modern aesthetic without cluttering the interface.
- Emphasize a minimalist and intuitive layout with generous whitespace. Prioritize responsiveness for optimal experience across all device sizes, especially crucial for the exam interface. Key information should be glanceable with clear hierarchies.
- Incorporate subtle and swift animations for transitions between pages and interactions (e.g., question navigation, button clicks) to enhance user experience without causing distractions or loading delays, reinforcing a sense of efficiency.
